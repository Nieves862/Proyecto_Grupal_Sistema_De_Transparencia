# Análisis de Datos Educativos de la Provincia de Córdoba

## Tercera Evidencia - Limpieza, Análisis y Visualización de Datos con Pandas y Matplotlib

Este repositorio contiene la tercera evidencia del proyecto de Aprendizaje Basado en Problemas (ABP), enfocada en el análisis de datos educativos de los 26 departamentos de la Provincia de Córdoba, Argentina. El objetivo principal fue realizar una limpieza exhaustiva del dataset, generar visualizaciones significativas y aplicar medidas descriptivas para comprender las características de las variables.

### 📊 Contenido del Repositorio

-   `Ev3AnalistadeDatos.ipynb`: Notebook de Jupyter con todo el código y las explicaciones del proceso de análisis.
-   `AnalisisdeDatos_EvIII`: Achivo PDF que contiene la documentacion del Proyecto
-   `Educacion.csv`: Archivo CSV con los datos educativos originales utilizados para el análisis.
-   `README.md`: Este archivo, que resume el proyecto.

### 📝 Objetivos de la Evidencia

1.  **Limpieza de Datos con Pandas**: Identificar y solucionar problemas comunes de calidad de datos, incluyendo:
    * Datos ausentes (valores nulos o "null").
    * Datos en formato incorrecto (fechas o texto en columnas numéricas).
    * Datos erróneos (inconsistencias en totales, valores atípicos).
    * Datos duplicados (filas completas o parciales).
2.  **Visualizaciones con Matplotlib**: Se crearon 4 gráficos relevantes para explorar las relaciones y distribuciones de los datos educativos, asegurando una correcta etiquetación.
3.  **Medidas Descriptivas**: Cálculo y análisis medidas descriptivas para variables numéricas y categóricas, incluyendo informes de simetría y asimetría.

### 🚀 Metodología

El análisis se llevó a cabo siguiendo una metodología estructurada, que incluyó los siguientes pasos:

1.  **Carga de Datos**: Importación del dataset `Educacion.csv` en un DataFrame de Pandas.
2.  **Inspección Inicial**: Revisión de la estructura del DataFrame, tipos de datos y búsqueda de valores nulos o inconsistencias obvias.
3.  **Limpieza de Datos**: Aplicación de diversas técnicas de Pandas para corregir los problemas de calidad de datos identificados. Se registraron  dos ejemplos de cada tipo de problema (ausentes, incorrectos, erróneos, duplicados) junto con su solución y el criterio adoptado.
4.  **Análisis Descriptivo**: Cálculo de estadísticas descriptivas (media, mediana, desviación estándar, etc.) y análisis de la asimetría y simetria de las variables numéricas.
5.  **Visualización de Datos**: Creación de gráficos utilizando Matplotlib para representar las distribuciones, comparaciones y relaciones entre las variables. Los gráficos incluyen:
    * Distribución de Alfabetización por Grupos de Edad (gráficos de torta).
    * Top 10 Departamentos por Población Universitaria (gráfico de barras).
    * Comparación de Niveles Educativos (gráfico de torta).
    * Relación entre Asistencia y Alfabetización (scatter plot con línea de tendencia).
6.  **Conclusiones y Recomendaciones**: Resumen de los hallazgos principales y recomendaciones para políticas públicas basadas en el análisis.
7.  **Definición de Producto Final**: Descripción de un "Dashboard Interactivo de Indicadores Educativos de Córdoba" como producto final, su vinculación con la comunidad y los espacios curriculares involucrados.
8.  **Bibliografía**: Listado de las referencias utilizadas, siguiendo las normas APA 7ma edición.

### 💡 Hallazgos Destacados

* El dataset original presentaba importantes desafíos en cuanto a la calidad de los datos, que fueron abordados sistemáticamente.
* Existe una notoria disparidad educativa entre los departamentos, con la Capital concentrando una gran proporción de la población educada.
* Los niveles de alfabetización son generalmente altos, especialmente en el grupo de 15 a 29 años.
* El acceso a la educación universitaria muestra la mayor variabilidad entre departamentos, sugiriendo posibles barreras geográficas y socioeconómicas.
