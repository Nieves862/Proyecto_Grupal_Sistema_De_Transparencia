# Evidencia II: Análisis Estadístico y Regresión en Reservas Hoteleras


---

## 📊 Objetivo del Análisis

El proyecto se centra en un **Informe de Análisis sobre el Dataset Hotel Booking**. Su propósito es identificar los factores clave que influyen en las ventas del sector hotelero y evaluar diferencias significativas entre grupos de reservas para una mejor toma de decisiones.

---

## 🛠️ Metodologías Aplicadas

El análisis estadístico y de modelado utiliza las siguientes técnicas principales:

1.  **Regresión Lineal Simple:** Para modelar la relación entre variables continuas (como 'price' y 'sales') y predecir las ventas.
2.  **Análisis de Varianza (ANOVA):** Para comparar las medias entre diferentes grupos y determinar diferencias estadísticamente significativas.

---

## 📝 Dataset

* **Nombre:** `hotel.csv` 
* **Contenido:** Datos reales de reservas de hoteles (Ciudad y Resort) de 2015 a 2017.
* **Variables:** Incluye 32 columnas con información detallada sobre la reserva, el huésped, la estadía y el precio.
